# Vyaj Hisab V5.8 Android APK

This Android wrapper contains the V5.8 web app and adds native WhatsApp file sharing.

## GitHub mobile build
1. Upload all files/folders in this project to the repository root (replace the old Android project files).
2. Open **Actions**.
3. Open **Build Vyaj Hisab APK**.
4. Tap **Run workflow** → **Run workflow**.
5. Wait for the green check.
6. Open the successful run and download the **Vyaj-Hisab-APK-V5.8** artifact.

The app's **📲 WhatsApp Par Bhejo** button creates the client HTML snapshot and shares it as a Document. If WhatsApp is installed, it targets WhatsApp directly; otherwise Android's share sheet is used.
